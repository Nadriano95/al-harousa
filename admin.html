Connexion

Connecte-toi avec un accès GitHub pour modifier les produits et photos du site directement en ligne.

Il te faut un token d'accès personnel GitHub (gratuit, à créer une seule fois) :
  1. Va sur github.com → Settings → Developer settings → Fine-grained tokens
  2. Nom : « Admin Al-Harousa », Expiration : 1 an
  3. Repository access → « Only select repositories » → choisis ton repo du site
  4. Permissions → « Contents » → Read and write
  5. Génère le token et colle-le ci-dessous
Ce token reste uniquement dans ton navigateur — il n'est jamais envoyé ailleurs qu'à GitHub.
Un token « fine-grained » limité à ce seul repo, avec permission Contents en lecture/écriture.
